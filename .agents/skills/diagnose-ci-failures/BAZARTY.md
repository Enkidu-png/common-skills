# Zmiany wzgledem warpdotdev/common-skills

- Kategorie bledow z Rusta (cargo fmt, clippy, WASM, platformy) zastapione strazniki `npm run check:*`, bledami `tsc`/`vite build`, testami i werdyktem bramki 2 = NIE SPRAWDZONO.
- Lista nazw checkow Warpa zamieniona na joby `zakres` i `ci` workflow `warp-ci.yml` na runnerze `mac-mini`.
- Narzedzie `create_plan` (Warp) zamienione na plan w trybie planu albo w odpowiedzi.
- Reszta przeplywu (gh pr view, gh run view --log-failed, plan przed kodem) bez zmian.

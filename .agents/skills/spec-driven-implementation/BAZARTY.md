# Zmiany wzgledem warpdotdev/common-skills

- Linear zamieniony na GitHub Issues w `Enkidu-png/bazarty-platforma` (`gh issue create`, etykiety z `.github/issue-triage/config.json`). Zakaz Linear: MCP Linear jest podlaczony do obcego workspace.
- Sciezki specyfikacji: `specs/GH<n>/product.md` i `tech.md` (pisownia jak regex `review-pr/scripts/resolve_spec_context.py`), obszary w `specs/<obszar>/PRODUCT.md`, `TECH.md` (decyzje w sekcji Decisions), zgodnie z `specs/README.md` repo bazarty.
- Makieta: Figma, plik HTML albo zrzut w repo. Zatwierdzenie specyfikacji = etykieta `ready-to-implement`.

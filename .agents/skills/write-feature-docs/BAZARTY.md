# Zmiany względem warpdotdev/common-skills (fork Enkidu-png/common-skills, gałąź bazarty)

- Wynik to Markdown po polsku w `docs/` repo bazarty (dokumenty dla człowieka) zamiast MDX w `warpdotdev/docs`; usunięte zależności od docs.warp.dev, Starlight, szablonów i zespołu docs Warpa.
- Recenzent to właściciel repo; dokumentację piszemy przy wydaniu, tylko dla funkcji już scalonych do `main`.
- Reguły stylu: głos marki (`docs/GLOS-MARKI.md`), „pracownia" zamiast „sklep", zakaz glifów-separatorów, bez emoji.
- Zrzuty na uruchomionej aplikacji na bazie DEV (Playwright albo przeglądarka) zamiast computer use Warpa; protokół weryfikacji zrzutu bez zmian.
